# Research Workspace

This directory separates local research assets from the tracked source tree.

- `research/working/`: scratch notes, prompts, dashboards, one-off exports, and experimental problem variants. Ignored in Git.
- `research/papers/`: local paper corpus and literature collections. Ignored in Git.
- `research/writing/`: manuscript drafts and LaTeX build outputs. Ignored in Git.

Tracked source and contributor docs stay under:

- `docs/` for stable protocol, migration, and reproducibility notes
- `docs/references.bib` for curated literature metadata used by the codebase and writing workflow
- `research/constraint_graph_policy_optimizer_proposal.md` for the lean CGPO method and paper-framing note

If you add new working research material, keep it under one of the ignored subdirectories here rather than at the repo root.
